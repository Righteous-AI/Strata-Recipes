# Recipe 3 — plain NVIDIA NVFP4, Strata 0.2.0-beta

The quality flags from [recipe 2](02-quality.md), on the 0.2.0-beta tree, still serving the plain NVIDIA NVFP4 pack. Not the running server. The running server is [recipe 4](04-fp4-local.md), which keeps these flags and changes the weights.

**Source of the rates:** real agent sessions, 2026-10-19 18:37 UTC boot, 72 finished requests, 82,003 generated tokens. The 19-against-13 worker trial later that evening is a bench and is not in this table.

| Bucket | 0.1.45 quality, 18:50 | This boot |
| --- | --- | --- |
| gen ≥ 200 | 134.3, median 132.4, n=6,721 | **146.5**, median **143.9**, 116.5–171.0, n=54, 80,598 tokens |
| Prompts 100k–200k, gen ≥ 200 | 132.8, median 130.7, n=3,765 | **143.3**, median **142.4**, n=33 |
| Prompts 50k–90k, gen ≥ 200 | 137.3, median 136.0, n=1,417 | **151.5**, median **150.4**, n=10 |
| Fresh reads ≥ 100k | 6,934.9, best 7,469.0, n=857 | **6,845.8**, best **6,939.4**, n=6 |
| Drafts, gen ≥ 200 | 70.2% | **66.7%** (45,270 / 67,829) |
| Expert-cache hit, gen ≥ 200 | | **91.4%** |

Decode is about 8% faster on 100k–200k prompts and about 10% faster on 50k–90k prompts. Long prefill is about 1% lower, on 6 reads against 857. Draft acceptance is a few points lower. No request fell to a few tok/s.

Config: [`configs/strata-nvfp4-nvidia.json`](../configs/strata-nvfp4-nvidia.json).

Pack: `/mnt/models/qwen/Strata-Qwen3.8-Flash-NVFP4`. `qwen-nvidia-nvfp4.gguf` is both `--native` and `--native-dense-gguf`. PLE is `ple-fp8.gguf` (47.68 GiB, FP8). MTP is `mtp-bf16/rt`. Experts are the 63.28 GiB pinned arena.

What 0.2.0 turns on by itself for this card, and what was left alone:

| Switch | This boot |
| --- | --- |
| `STRATA_SM120_PERF` unset | On. Side mixer, daily attention, the GR and SwiGLU kernels, and the sm_120 MMVQ table. Bitwise with the kernels they replace. |
| `STRATA_PF_FUSED` | Not taken. It covers IQ packs, not NVFP4. |
| `--pool-workers` | The 18:37 boot used 19. The config is 13 as of 2026-10-21. The matched bench that evening was under 3%. The later five-run sweep is in [rejected.md](../rejected.md). |
| `--vram-reserve-mib 512` | Kept. The boot reports about 141 MiB free and suggests a higher reserve. Raising it shrinks the expert cache. |
| `STRATA_PREFILL_HOST_PLAN=0` | Pinned. A no-op on this arena. |
| Context 262,144, `auto:32768`, spec 4, spec-min-p 0.5, adapt 1 / 160 / 0.97 | Unchanged from recipe 2. |

Boot shape of that session: 19 workers on CPUs 1–19, prompt chunk 32,768, 9,075 slots, 23.87 GiB cache, KV 32,768 of 262,144. Arena pinned at about 3.7–4.1 GiB/s. PCIe probe about 46 GB/s, then the share moves to 0.30. The config file is 13 workers as of 2026-10-21. The rates in the table above are the 19-worker boot.

The full old-against-new table is in [comparisons.md](../comparisons.md).
